# Watchly Website

Sitio web independiente de Watchly.

## Páginas

- `index.html` — landing page de Watchly.
- `privacy.html` — política de privacidad inicial.
- `assets/styles.css` — estilos.
- `assets/favicon.svg` — favicon.

## Publicación

Es un sitio estático y puede alojarse en GitHub Pages, Netlify, Cloudflare Pages, Vercel o cualquier hosting estático.

La URL de `index.html` puede utilizarse como **Application URL** al registrar Watchly en TMDB.

## TMDB

El sitio incluye la atribución y el aviso de TMDB requeridos para describir el uso de su API:

"This product uses the TMDB API but is not endorsed or certified by TMDB."
