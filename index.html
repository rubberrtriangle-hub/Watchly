SOBRE WATCHLY

Una app sencilla para una pregunta sencilla.

Watchly es un proyecto Android independiente centrado en el seguimiento de películas, series y franquicias. Su objetivo es darte una imagen útil de tu progreso sin convertir tu biblioteca en una tarea.

La aplicación está pensada para ser gratuita y sin anuncios. Los datos de catálogo que Watchly necesita se obtienen mediante la API de TMDB.

FUENTE DE DATOS

Contenido impulsado por TMDB.

Watchly utiliza la API de The Movie Database (TMDB) para obtener información de películas, series e imágenes.

This product uses the TMDB API but is not endorsed or certified by TMDB.
